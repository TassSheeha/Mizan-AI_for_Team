# ElevenLabs workflow definitions

Place workflow definitions here. ElevenLabs workflows define the call flow:

1. Call initiation — dial, wait, greet
2. Identity verification — confirm customer identity
3. Purpose disclosure — why we're calling (CBUAE disclosure requirement)
4. Balance presentation — read outstanding amount
5. Solution offering — present ranked options
6. Payment processing — guide through payment
7. PTP / escalation — handle promises to pay or escalation
8. Call closure — summary, recording disclosure, hangup
