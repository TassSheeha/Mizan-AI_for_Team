# ⚖️ الميزان (Mizan AI) — المستشار القانوني الليبي الذكي

### مساعد ذكي عربي مبني على تقنية RAG للمعلومات القانونية والحكومية الليبية

---

## 🌟 نظرة عامة

**الميزان** هو النسخة المدمجة والمحسّنة من النموذجين الأوليين، تجمع أفضل ما في كليهما:

| الميزة | المصدر | الوصف |
|---|---|---|
| **12 تشريعاً ليبياً** | النموذج الثاني + الأول | 2,929 مادة ومقطع قانوني مفهرس (أُضيف قرار 888/2023 التنفيذي لقانون العمل) |
| **استرجاع هجين** | كلاهما | بحث دلالي (ChromaDB + multilingual-e5-small) + بحث كلمات (BM25 عربي) مدموجان عبر RRF |
| **ذاكرة حوارية** | النموذج الثاني | متابعة الأسئلة التابعة ("ما عقوبتها؟") مع إعادة صياغة آلية للسؤال قبل البحث |
| **بوابة ملاءمة متعددة المعايير** | النموذج الأول (مُصححة) | دمج كثافة دلالية + BM25 + درجة ثقة موزونة — تمنع الهلوسة والإجابات خارج النطاق |
| **بث تدريجي (Streaming)** | النموذج الأول | الإجابة تظهر كلمة كلمة من Groq أو Ollama |
| **مقاييس أداء حية** | النموذج الأول | زمن البحث، زمن التوليد، المزود، درجة الثقة لكل إجابة |
| **محرك منع التكرار** | النموذج الثاني | تنقية دلالية على مستوى الجمل والفقرات (Jaccard) لمنع حشو النماذج |
| **كشف التحيات الذكي** | النموذج الثاني | ردود ترحيب فورية دون استهلاك نماذج التوليد |
| **تصفية المصادر** | النموذج الأول | حصر البحث في قانون محدد من القائمة الجانبية |
| **دعم اللهجة الليبية** | كلاهما | توسيع آلي لاستعلامات "شن/قداش/نبي/فصلوني..." بمقابلات فصحى قانونية |

## 💻 المتطلبات

1. **نظام التشغيل:** Windows (يوصى به) أو Mac أو Linux.
2. **Python:** إصدار 3.10 أو أحدث ([python.org](https://www.python.org/downloads/)).
3. *(اختياري — للتوليد الذكي الكامل):* **مفتاح Groq API مجاني** من [console.groq.com](https://console.groq.com)، أو تشغيل **Ollama** محلياً. بدون أي منهما يعمل التطبيق بـ**النمط المدمج التلقائي** (عرض المواد المسترجعة بصياغة مترابطة) بدون إنترنت أو مفاتيح.

> ملاحظة: موديل التضمين (ONNX multilingual-e5-small) يُنزَّل تلقائياً من HuggingFace عند أول تشغيل (~90 ميجابايت) ويُخزَّن محلياً.
>
> ملاحظة: إعادة معالجة الوثائق الممسوحة ضوئياً (خط `run_pipeline.py`) تتطلب ويندوز 10/11 — حزمة `winocr` (Windows Media OCR) تُثبَّت تلقائياً من `requirements.txt` على ويندوز فقط.

> ملاحظة: قرار مجلس الوزراء رقم (888) لسنة 2023 مفهرس حالياً بست مواد فقط بسبب جودة المسح الضوئي للنسخة المتاحة؛ يُنصح بتوفير نسخة أوضح لإعادة الفهرسة الكاملة.

## 🚀 طريقة التشغيل السريعة

### 🪟 لمستخدمي ويندوز (بنقرة واحدة):
انقر مرتين على الملف:
```
run_app.bat
```
يقوم تلقائياً بإنشاء البيئة الافتراضية، تثبيت المتطلبات، وتشغيل واجهة المتصفح.

### 💻 أو يدوياً عبر سطر الأوامر:
```bash
python -m venv .venv
.venv\Scripts\Activate.ps1        # Windows
# source .venv/bin/activate       # Mac/Linux

pip install -r requirements.txt
streamlit run app.py
```

### ⌨️ واجهة سطر الأوامر (CLI مع ذاكرة محادثة):
```bash
python chat_cli.py
python chat_cli.py --query "شن شروط إجازة الحج؟"
python chat_cli.py --groq-key "gsk_..."
```

### 🧪 تقييم جودة الاسترجاع:
```bash
python evaluation\test_retrieval.py
```

### 📊 منظومة الاختبار والتقييم الشاملة (8 أبعاد):
```bash
python evaluation\run_all.py                 # كاملة: 8 أبعاد
python evaluation\run_all.py --skip-voice    # بدون اختبارات الصوت (أسرع)
python evaluation\run_all.py --module voice  # بعد واحد فقط
```
الأبعاد المغطاة: الاسترجاع (Recall@1/3/5 + MRR)، جودة الإجابة والتحقق من التأسيل، السند القانوني، الرفض (خارج النطاق/لا أعرف/الغامض)، الصوت (WER + اللهجة الليبية + TTS)، النظام الكامل (multi-turn + stress)، جودة البيانات (تكرارات + قابلية التوسع)، والسلامة (التنويه + تعارض المصادر). تُكتب النتيجة في `evaluation/report.md`، والردود المخصصة للمراجعة البشرية في `evaluation/manual_review_answers.md`.

## 📂 خريطة الملفات

| المسار | الوظيفة |
|---|---|
| `app.py` | واجهة الويب (Streamlit): شات متدفق، بطاقات سند، مقاييس، تخصيص كامل |
| `chat_cli.py` | واجهة طرفية تفاعلية مع ذاكرة محادثة |
| `config.py` | سجل الوثائق الـ 12 وإعدادات الاسترجاع والـ OCR |
| `mizan/assistant.py` | المنسق الرئيسي: كشف التحيات، بوابة الملاءمة، الذاكرة، البث |
| `mizan/retriever.py` | الاسترجاع الهجين: Dense + BM25 + RRF + تصفية الميتاداتا |
| `mizan/generator.py` | التوليد: Groq / Ollama / النمط المدمج + منع التكرار + إعادة صياغة المتابعات |
| `mizan/bm25_search.py` | محرك BM25 العربي (تطبيع الحروف والتشكيل) |
| `scripts/` | خط معالجة الوثائق (استخراج → تنظيف → هيكلة → تقطيع → فهرسة) |
| `scripts/add_chunks_to_index.py` | إضافة وثيقة مُقطَّعة جاهزة إلى الفهرس دون إعادة بناء |
| `evaluation/test_retrieval.py` | اختبارات جودة الاسترجاع (مواد محددة، لهجة، مفاهيم) |
| `data/` | القاعدة المفهرسة كاملة جاهزة للاستخدام الفوري (chroma_db + chunks + raw) |

## ➕ إضافة تشريع جديد

1. ضع ملف الـ PDF في `data/raw/`.
2. أضف سطراً جديداً في `DOCUMENTS` داخل `config.py` (يوجد قالب جاهز في التعليقات).
3. شغّل خط المعالجة ثم أعد بناء الفهرس:
   ```bash
   python scripts\run_pipeline.py
   python scripts\embed_and_index.py
   ```

## ⚙️ قرارات هندسية مهمة (لل reviewer)

- **بوابة الملاءمة** (`mizan/assistant.py`): درجة الثقة تُحسب من **التشابه الدلالي الموزون بالرتب** وليس من درجة RRF (كانت في النموذج الأول تحسب من RRF فلا تتجاوز 0.02 أبداً — عيب تم إصلاحه).
- **منع تكرار دورة السؤال** (`app.py`): تاريخ المحادثة يُلتقط *قبل* إضافة السؤال الحالي، لأن `generate()` يضيفه بنفسه — إضافة مزدوجة تسبب حلقات تكرار.
- **التنظيف بعد البث** (`generator.clean_answer`): يُطبَّق على النص الكامل بعد انتهاء البث لأن الإزالة التكرارية أثناء البث غير ممكنة.
- **فهرس متوافق:** اسم مجموعة ChromaDB ومخطط الميتاداتا مطابقان للنموذج الثاني، مع إضافة `doc_id` لكل مقطع لتمكين تصفية المصادر.
